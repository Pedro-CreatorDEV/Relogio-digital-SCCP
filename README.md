### 🎯 Sobre o Projeto & Personalização
Este projeto nasceu a partir de uma videoaula de desenvolvimento front-end do canal da **[Larissa Kich](https://www.youtube.com/@LarissaKich)** no YouTube, onde explorei os fundamentos de manipulação do DOM e atualização dinâmica de tempo com JavaScript puro.

A partir da estrutura base da aula, **adaptei e personalizei o projeto aos meus gostos**, aplicando uma estética exclusiva inspirada no **Corinthians (SCCP)** — ajustando paleta de cores, tipografia, elementos visuais e organização dos ativos para transformar um exercício prático em uma interface com identidade própria.

---

### ✨ Funcionalidades & Destaques
- **Sincronização em Tempo Real:** Atualização contínua de **horas, minutos e segundos** utilizando o objeto `Date` e `setInterval` do JavaScript.
- **Identidade Visual Customizada:** Estilização temática em preto e branco com escudo e elementos gráficos do **SCCP**.
- **Interface Limpa e Responsiva:** Cards individuais com contraste elevado para leitura rápida em diferentes tamanhos de tela.
